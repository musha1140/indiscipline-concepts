The ticket workflow

  1. Add the show. Set its date, venue, times, prices and opening act.
  2. Paste its TicketWeb event link. That one destination supplies the selected show’s ticket buttons and any new QR.
  3. Review, then publish and feature. TicketWeb continues to handle checkout and ticket delivery.
  4. Create promotion. Generate a flyer from the same approved details; preserve the existing October 16 QR or explicitly generate a new one.
